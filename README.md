# 🎮 Game Meta Assistant  
**PT-BR | EN Below**

Um assistente inteligente projetado para ajudar jogadores a analisar estratégias, obter dicas, estudar metas e tirar dúvidas sobre seus jogos favoritos usando **IA via Gemini API**.

---

## 🇧🇷 **Sobre o Projeto (PT-BR)**  
O **Game Meta Assistant** permite que o usuário insira sua própria **API Key do Gemini** e faça perguntas sobre jogos, builds, metas atuais e estratégias.  
As respostas são geradas de forma contextual e adaptadas ao jogo mencionado.

### ✨ Funcionalidades  
- 🔑 Inserção segura da API Key  
- ❓ Perguntas livres sobre qualquer jogo  
- 🕹️ Respostas focadas em meta, builds e estratégias  
- ⚡ Interface simples, direta e rápida  

### 🛠️ Tecnologias  
- HTML / CSS / JavaScript  
- Google Gemini API  
- Fetch API  

### 📚 Exemplos de Perguntas  
- *"Qual a melhor build para o personagem X no patch atual?"*  
- *"Qual estratégia está forte no Valorant no momento?"*  
- *"Qual arma está no meta atual do Warzone?"*

### ⚠️ Aviso  
A API Key **não é armazenada** ou enviada a nenhum servidor.  
Todo o processamento ocorre **localmente no navegador** do usuário.

---

# 🇺🇸 **About the Project (EN)**  
The **Game Meta Assistant** is an intelligent tool that helps gamers analyze strategies, explore current metas, get gameplay tips, and ask any game-related questions using the **Gemini API**.

### ✨ Features  
- 🔑 Secure input for the user’s Gemini API Key  
- ❓ Free-form gaming questions  
- 🕹️ Meta-focused answers: builds, strategies, updates  
- ⚡ Clean and responsive interface  

### 🛠️ Technologies  
- HTML / CSS / JavaScript  
- Google Gemini API  
- Fetch API  

### 📚 Example Questions  
- *"What is the best build for character X in the current patch?"*  
- *"What's strong in Valorant right now?"*  
- *"What’s the current meta weapon in Warzone?"*

### ⚠️ Important  
Your API Key is **not stored**, **not logged**, and **never sent** to external servers.  
All processing is performed **locally** in the browser.
