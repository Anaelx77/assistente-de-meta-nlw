# 🎮 Game Meta Assistant  
Um assistente inteligente para jogadores que desejam analisar estratégias, obter dicas e tirar dúvidas sobre seus jogos utilizando IA via **Google Gemini API**.

## 🚀 Sobre o Projeto  
O **Game Meta Assistant** permite que o usuário insira sua própria **API Key do Gemini** e faça perguntas sobre jogos, estratégias, builds, metas atuais e qualquer dúvida relacionada ao universo gamer.  
A IA responde de forma contextual, auxiliando jogadores iniciantes e experientes.

## 🧠 Como Funciona  
1. O usuário insere sua **API Key do Gemini**.  
2. A aplicação envia perguntas diretamente para o modelo da Google via API.  
3. O assistente retorna análises, metas, dicas e informações úteis sobre o jogo especificado.

Isso garante segurança, privacidade e total controle da chave pelo usuário.

## ✨ Funcionalidades  
- 🔑 Campo seguro para inserir e validar API Key  
- ❓ Envio de perguntas personalizadas  
- 🕹️ Respostas com foco em metas e estratégias de jogos  
- ⚡ Respostas rápidas e contextualizadas  
- 💬 Interface simples e intuitiva  

## 🛠️ Tecnologias Utilizadas  
- **HTML / CSS / JavaScript**  
- **API Google Gemini**
